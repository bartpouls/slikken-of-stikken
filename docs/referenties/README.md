# Referentiebeelden

Schermafbeeldingen die als stijl- en opbouwreferentie dienen voor de bouw van Slikken of Stikken. Ze laten zien welke sfeer, opbouw en manier van vertellen we zoeken. Het spel neemt er niets uit over: geen beeld, tekst, code of geluid.

| `evolution-of-trust.png` | The Evolution of Trust | Nicky Case | https://ncase.me/trust/ |
